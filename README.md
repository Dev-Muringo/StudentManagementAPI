# Student Management API

A RESTful API built with Node.js, Express.js and PostgreSQL to manage student records.

## Version 1.0 – Current Features

- Student registration
- Student login
- Password hashing using Argon2id
- Student profile picture uploads
- Image signature validation
- PostgreSQL database integration
- Input validation
- Layered architecture (Routes, Controllers, Services and DAO)

## Technologies Used

- Node.js
- Express.js
- PostgreSQL
- Argon2
- Multer
- Git and GitHub
